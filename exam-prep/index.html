Confusing pairs

The look-alikes Microsoft uses as distractors.

Each card names the services, the one job each does, and the phrase in the question that gives the answer away.

Policy vs RBAC vs Locks

Lesson →
Azure Policy
What configuration is allowed (regions, SKUs, tags)
Azure RBAC
Who can do which actions at which scope
Resource locks
Stop delete (CanNotDelete) or any change (ReadOnly), even for Owners

"Only these regions" → Policy. "Let Ana restart VMs" → RBAC. "Nobody deletes this" → Lock.

Blueprints vs ARM templates / Bicep

Lesson →
Azure Blueprints
Old package of templates + policy + roles — retired in July 2026
ARM templates / Bicep
Current infrastructure as code, deployed through Azure Resource Manager

Blueprints are a legacy distractor. Repeatable deployments today → ARM templates or Bicep (plus Policy).

Advisor vs Service Health vs Monitor

Lesson →
Azure Advisor
Recommendations: cost, security, reliability, performance, operational excellence
Azure Service Health
Microsoft's incidents and maintenance affecting your subscriptions
Azure Monitor
Your metrics and logs, alerts, Log Analytics, Application Insights

"How can I improve?" → Advisor. "Is Azure broken for me?" → Service Health. "What is my app doing?" → Monitor.

NSG vs Azure Firewall vs DDoS Protection

Lesson →
Network security group
Basic allow/deny port and IP rules on a subnet or NIC
Azure Firewall
Managed, stateful, central firewall with FQDN and threat-intel rules
DDoS Protection
Absorbs traffic floods aimed at public endpoints

Simple port rules → NSG. Central managed firewall → Azure Firewall. Flood attack → DDoS Protection.

VPN Gateway vs ExpressRoute vs VNet peering

Lesson →
VPN Gateway
Encrypted tunnel to on-premises over the public internet
ExpressRoute
Private connection to on-premises, not over the internet
VNet peering
Connect Azure VNets to each other over the Microsoft backbone

"Encrypted over the internet" → VPN. "Not over the internet" → ExpressRoute. VNet-to-VNet → peering.

Availability set vs availability zone vs region pair

Lesson →
Availability set
Spread VMs across racks and host updates in one datacenter
Availability zone
Separate datacenters inside one region
Region pair
Two regions for disaster recovery

Rack failure → set. Datacenter failure → zones. Whole region down → pair.

Pricing Calculator vs Cost Management vs Migrate business case

Lesson →
Pricing Calculator
Estimate Azure cost before you deploy
Microsoft Cost Management
Analyze real spend, set budgets and alerts
Azure Migrate business case
Compare on-premises vs Azure (replaces the retired TCO Calculator)

Before → Calculator. After → Cost Management. Should we migrate? → business case.

Reservations vs savings plan vs Spot

Lesson →
Reservations
Commit to a specific resource for 1 or 3 years
Savings plan for compute
Commit to hourly compute spend; flexible across sizes and regions
Spot
Deep discount on spare capacity; can be evicted

Steady and fixed → reservation. Steady spend but changing shape → savings plan. Interruptible → Spot.

Purview vs Policy vs Service Trust Portal

Lesson →
Microsoft Purview
Discover, classify, and govern data
Azure Policy
Enforce resource configuration rules
Service Trust Portal
Download Microsoft's audit reports and compliance documents

Data → Purview. Resources → Policy. Microsoft's proof for auditors → Service Trust Portal.

Entra ID vs Entra Domain Services vs Conditional Access

Lesson →
Microsoft Entra ID
Cloud identity: sign-in, SSO, MFA (formerly Azure AD)
Entra Domain Services
Managed domain join, LDAP, Kerberos for legacy apps
Conditional Access
If/then rules on sign-in signals (location, device, risk)

Modern sign-in → Entra ID. Legacy domain features → Domain Services. "If X then require MFA" → Conditional Access.

Cool vs Cold vs Archive

Lesson →
Cool
Online, infrequent access, about 30 days minimum
Cold
Online, rarely accessed, about 90 days minimum
Archive
Offline, hours to rehydrate, about 180 days minimum

Need it instantly? Not Archive. Cold is still online.

Azure AI services vs Azure Machine Learning

Lesson →
Azure AI services
Prebuilt models behind APIs (vision, speech, language)
Azure Machine Learning
Train, deploy, and manage your own models

No data scientists → AI services. Custom models → Machine Learning.

Exam-day guide

Know the format so nothing surprises you.

Details come from the official certification page and exam policies. Microsoft updates these occasionally — check the exam page before you book.

Exam time
45 minutes of answering time; plan for about 65 minutes in the seat with the agreement and survey.
Questions
Usually 40–60. Some unscored questions may be included — you will not know which.
Passing score
700 on a 1–1000 scaled score. It is not a straight percentage.
Question types
Multiple choice, multiple response (choose two), Yes/No statement sets, sentence completion (drop-down), drag-and-drop matching. No hands-on labs.
Where
Pearson VUE (test center or online proctored at home) or Certiport if you are a student or educator.
Results
Pass/fail appears on screen right after the exam, with a score report by skill area.
Retake policy
Wait 24 hours after a first failed attempt, then 14 days between later attempts, with at most 5 attempts in 12 months.
Validity
Fundamentals certifications do not expire and do not need renewal.

Tactics that earn points

  • ✦Try the free Microsoft practice assessment and the exam sandbox once before exam day.
  • ✦Unanswered questions score zero and there is no penalty for guessing — never leave a blank.
  • ✦Read the last line of the question first, then the scenario. Look for words like BEST, MOST, LEAST, and NOT.
  • ✦In Yes/No sets, judge each statement on its own — they are independent.
  • ✦Use Mark for review and keep moving; come back with the time you saved.
  • ✦Old names still appear: Azure AD = Microsoft Entra ID, Azure Security Center = Defender for Cloud.
  • ✦For online proctoring: clear desk, ID ready, close every app, and run the system test the day before.
